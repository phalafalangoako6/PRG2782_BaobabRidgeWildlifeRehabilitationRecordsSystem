2. Project Overview
A C# Windows Forms for managing wildlife rehabilitation records using text files.

   ---
3. Features
Add animal records
View animal records
Update animal records
Delete animal records
Generate a summary report

   ---
4. File Formats 
animal.txt: Stores animal records using pipe-separated fields.
summary.txt: Stores the generated summary report.

Open the solution in Visual Studio, build the project and run the application.
